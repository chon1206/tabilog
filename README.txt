tabilog — iPhoneのホーム画面に置けるアプリ

【GitHub Pagesで公開】
1. GitHubで新しいリポジトリを作る（名前：tabilog / Public）
2. 「uploading an existing file」→ このフォルダの中のファイルをすべて選んでアップロード → Commit changes
3. Settings → Pages → Branch を main / (root) にして Save
4. 1〜2分後に https://ユーザー名.github.io/tabilog/ ができる

【iPhoneに入れる】
SafariでそのURLを開く → 共有ボタン → 「ホーム画面に追加」
